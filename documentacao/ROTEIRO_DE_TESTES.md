# Roteiro de testes

Marque cada item depois de executar e registre os resultados na documentação.

- [ ] Apache e MySQL iniciam no XAMPP.
- [ ] O banco `controle_equipamentos` foi criado.
- [ ] As tabelas `equipamentos` e `emprestimos` existem.
- [ ] A aplicação abre em `http://localhost/NOME_DA_PASTA/`.
- [ ] A conexão PHP com o banco funciona.
- [ ] É possível cadastrar um equipamento.
- [ ] Patrimônio duplicado é recusado.
- [ ] A pesquisa encontra equipamentos.
- [ ] É possível registrar um empréstimo.
- [ ] O equipamento emprestado fica indisponível.
- [ ] É possível registrar uma devolução.
- [ ] O equipamento devolvido fica disponível.
- [ ] Foi feito backup antes da migração.
- [ ] O CSV foi importado.
- [ ] A quantidade de registros foi conferida.
- [ ] A documentação tem capturas de tela e resultados dos testes.
